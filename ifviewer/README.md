# ifviewer

Viewer for IF. Firefox for Android + Tampermonkey (PC works too).

**[Install / update](https://raw.githubusercontent.com/YoruCAnime/Anilist/ccr-dead577e-viwlwo/ifviewer/ifviewer.user.js)**

- The whole gallery opens as one scroller of the original pictures and GIFs, starting at the page you opened.
- Originals load a few screens ahead.
- Long-press (right-click on PC) saves the original. Each picture also has a ⬇ button.
- Your place is remembered: back, reload or reopening later returns to the same picture.
- Counter (top right) jumps to a picture number. ✕ shows the normal page.

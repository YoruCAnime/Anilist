# AniList tools

by **YoruC**

| Tool | For | |
|---|---|---|
| **AniList Chat Compressor** | PC (Chrome, Brave, Edge, Firefox + Tampermonkey) | [Guide + install](chat-compressor-pc) |
| **AniList Chat Compressor (Mobile)** | Firefox for Android (Violentmonkey / Tampermonkey) | [Guide + install](chat-compressor-mobile) |
| **AniList GIF & Picture Picker** | PC + Firefox for Android (Tampermonkey) | [Guide + install](gif-picker) |
| **AniList Like Previews** | PC (Chrome, Brave, Edge, Firefox + Tampermonkey) | [Guide + install](like-previews) |
| **AniList DMs** | PC + Firefox for Android (Tampermonkey) | [Guide + install](dms) |

The Chat Compressors make long AniList reply threads open instantly: the newest messages first, in a compact
chat view that checks for new messages by itself.

The GIF & Picture Picker adds a GIF button to AniList's comment toolbar: search Tenor GIFs and SFW anime art
(Safebooru, Konachan), see previews, tap one (or pick several) and `img(link)` is in your comment, at any size.
It can also upload your own GIFs and videos to your GitHub repos.

Like Previews adds tabs to the notifications page (Likes, Messages & mentions, Replies, Other) and shows what
people liked as small cover squares.

DMs puts your private AniList message chats behind a small chat button in the bottom-right corner of every
page: newest messages first, a red number for new ones, live preview, likes, reply, edit and delete.
